# 7 Epic shadcn Blocks & Libraries You Should Know

These curated shadcn kits have **playful UI patterns**, **micro interaction** and **fresh looking backgrounds** built around animation‑first blocks, plus fresh **visual trends and effects**. Remembering all these libraries can be a lot, use [Shoogle](https://shoogle.dev/) to search across them all.


## Componentry.fun / Free

[Componentry.fun](https://componentry.fun/) is a curated set of **animation‑first** React components built with Tailwind, TypeScript, and Framer Motion, focused on making small interactions feel intentional rather than decorative.



## Skiper UI / Free & Paid

[Skiper UI](https://skiper-ui.com/) is a collection of **uncommon** React components built on top of shadcn/ui and Tailwind, aimed at product teams who care about interaction quality as much as layout. Instead of yet another set of generic buttons and cards, you get production-ready “product slices” for real use cases: scroll effects, interactive sections, auth flows, dashboards, and marketing surfaces wired with thoughtful motion and sensible defaults.


## Cult UI Pro / Paid

[Cult UI Pro](https://pro.cult-ui.com/?atp=atpc) is the paid layer on top of Cult UI. Cult UI Pro is a **full‑stack** extension of the shadcn ecosystem that gives you opinionated blocks, data‑aware patterns, and complete templates built with Next.js 16, Vercel AI SDK, and Tailwind. What makes it unique is how it treats UI as part of an application skeleton rather than isolated components: you get ready‑wired flows for AI agents, server actions, onboarding, dashboards, and marketing pages, so the same block covers layout, motion, and backend integration.


## Unlumen UI / Free & Paid

[Unlumen UI](https://ui.unlumen.com/) is a **motion‑driven** component library for React, built with TypeScript, Tailwind, and Motion, that leans hard into complex, well‑tuned animations for things like tooltips, cursors, buttons, and previews. What’s actually unique is the level of craft in those interactions: components are forked and evolved from Animate UI with a strong emphasis on timing, easing, and layered states, so behaviors like hover, focus, entry, and exit feel cohesive across the entire set instead of being one‑off tricks.


## Watermelon.sh / Free

[Watermelon UI](https://ui.watermelon.sh/) is a **studio‑quality** set of React components, dashboards, and blocks built with Tailwind and Radix, designed to feel like they came out of the same design ecosystem that powers Watermelon’s broader product suite (Studio, Native, AI, etc.).


## Morphin / Free & Paid

[Morphin.dev](https://morphin.dev) is a premium React UI library focused on animated components and micro-interactions built with Framer Motion. It's basically a curated collection of production-ready motion patterns for developers who want to add polished animations to modern product interfaces without building them from scratch

---

## aliimam.in / Free

[Alimam](https://aliimam.in/) is a huge collection of shadcn blocks and components, authored by one person who treats the site as both a portfolio and an evolving design system. Instead of a faceless “UI kit,” you’re tapping into a working designer’s real production stack, with components, vectors, and blocks that are shaped by client work, branding projects, and actual shipped interfaces.
