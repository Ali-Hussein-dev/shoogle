## Devl
[devl.dev](https://devl.dev/?utm_source=shoogle.dev&utm_medium=referral&utm_campaign=directory) is a gallery of UI design experiments and components built on top of the coss-ui React + Tailwind component system. It showcases 150+ experimental interfaces whose source you can inspect and copy, and many of those components are published through the shadcn UI registry for reuse in your own projects.

<img width="3697" height="1922" alt="image" src="https://github.com/user-attachments/assets/de1a1010-796d-4171-8302-11e6b2d44d44" />

## Shieldcn
[Shieldcn](https://shieldcn.dev/?utm_source=shoogle.dev&utm_medium=referral&utm_campaign=directory) is a badge generator for GitHub READMEs and other Markdown docs, focused on making badges that look like shadcn/ui buttons instead of the usual flat shields.io style

<img width="3815" height="1931" alt="image" src="https://github.com/user-attachments/assets/337e5e54-936b-408e-b4f5-89a916c40525" />

## Dot Matrix
[Dot Matrix](https://dotmatrix.zzzzshawn.cloud/?utm_source=shoogle.dev&utm_medium=referral&utm_campaign=directory) is a small React component library of 55+ dot‑matrix style loading animations built with TypeScript, Tailwind, and shadcn.

<img width="3815" height="1931" alt="image" src="https://github.com/user-attachments/assets/f0fcfd4d-a133-4c19-b2ff-65836de59562" />


## EvilChart
[EvilCharts](https://evilcharts.com/?utm_source=shoogle.dev&utm_medium=referral&utm_campaign=directory) is an open-source chart UI website built with shadcn and Recharts, beautifully designed and handcrafted. This library is not really released in April 2026, but it resereved its namespace from the shadcn registry recently.

<img width="3693" height="1923" alt="image" src="https://github.com/user-attachments/assets/f3908008-48a3-4061-9cee-c8d56a7a4037" />


## Flightcn
[Flightcn](https://flightcn.yencheng.dev/?utm_source=shoogle.dev&utm_medium=referral&utm_campaign=directory) is a small React component library for visualizing flight networks on interactive maps, built on top of mapcn. It gives you prebuilt components like FlightAirport, FlightRoute, FlightRoutes, and FlightMultiRoute to render airports, single routes, batches of routes, and multi‑leg itineraries with animation and hover details
